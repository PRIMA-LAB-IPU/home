# PRIMA LAB website

岩手県立大学PRIMA研究室の静的サイト。`index.html` を開くと動作します。HTML・CSS・JavaScriptのみで、npmやビルドは不要です。GitHub Pagesのリポジトリ配下にも対応しています。

## 2026-09-26 更新

- 提供された正式ロゴ2種をヘッダー、教員紹介、フッター、faviconに使用。
- Exploration 001に5研究テーマの3Dオブジェクトを配置。ドラッグ、回転スライダー、視点ボタンで技術・社会・つくるの説明を切替。
- 超音波、Wi-Fi DensePose、木の成長、図面加工、インフラツーリズムに操作できる3D概念体験を追加。
- 2年生向けの興味選択、最初の実験例、見学案内、FAQを追加。
- 合宿・地域活動・国際発信の紹介を追加。
- 日英対応。PC・スマートフォン対応。デモは模擬データであり実際の推論や予測ではありません。

## 編集するファイル

| ファイル | 内容 |
| --- | --- |
| index.html | 基本構造、ロゴ、トップ画面 |
| styles.css | レイアウト、色、レスポンシブ対応 |
| research-data.js | 5テーマの日英テキスト、視点別説明、課題 |
| lab3d.js | 3D座標投影・モデル・描画 |
| app.js | トップの3D空間とテーマ選択 |
| playground.js | 研究デモ、パラメーター、視点操作・リセット |
| community.js | 2年生案内、興味選択、FAQ、活動紹介 |
| content.js | セクション生成、言語切替、論文一覧 |
| SOURCES.md | 研究・画像の出典と掲載方針 |

外部ライブラリやWebGLへの依存はありません。3D座標をCanvasへ透視投影しています。ロゴや研究写真はローカルに同梱。Google Fontsが使えない環境では端末のフォントにフォールバックします。

## 操作

- トップ: オブジェクトのラベルで研究テーマを選択。角度で説明を変更。「この研究で遊ぶ」で該当デモへ移動。
- 研究タブ: 左右矢印・Home・Endにも対応。
- 各デモ: ドラッグまたは正面・横・下からのボタンで回転。スライダーとチェックボックスで変化させ、リセットで初期状態へ。
- 自動回転: 全3Dで初期自動回転。停止・再開ボタンあり。操作中は停止、タブ非表示時は描画を休止。研究デモは画面外でも描画を休止。
- お問い合わせ: メールアプリを開くリンク。自動送信や解析ツールなし。
- JavaScript無効時: 基本案内と現行サイトへのリンクを表示。

## GitHub Pages

公開先リモートは `https://github.com/PRIMA-LAB-IPU/home.git`。この更新ではローカルのソースのみ編集し、commit / push / 公開は行っていません。

1. Settings → Pages → SourceでGitHub Actionsを選択。
2. ファイル一式をmainへpushするか、ActionsでDeploy PRIMA LAB to GitHub Pagesを手動実行。
3. workflowは全JavaScriptを構文チェックし、ページとassetsだけを公開します。

独自ドメインのDNSや既存サイトの設定は変更していません。

- 超音波体験: CC0の公開画像を6つの仮想位置へ配置。実測連続断面や診断用の再構成ではありません。出典はSOURCES.md。
- Research Passport: 5テーマのミッション達成をページ内で記録。再読み込みでリセット。
